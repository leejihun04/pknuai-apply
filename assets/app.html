pknuai 로그인 연결

부경대 포털 로그인은 휴대폰 인증으로 끝나서 프로그램이 대신 로그인할 수 없습니다. 브라우저에서 로그인한 세션을 가져오면 됩니다 — 아래 버튼 한 번이면 충분합니다.

직접 붙여넣기 (위 방법이 안 될 때)
  1. 브라우저에서 비교과 프로그램 목록에 로그인합니다.
  2. 개발자도구(F12) → 네트워크 탭 → 새로고침 → program.do 요청 클릭.
  3. 요청 헤더의 Cookie 값을 통째로 복사해 아래에 붙여넣습니다.
